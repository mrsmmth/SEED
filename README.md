# SEED — Spherical Notes

白い宇宙に自由記述メモを浮かべる、iPad向けの球体型Webアプリです。

## 操作

- 空白をドラッグ：球体を回転
- ピンチ：大きく拡大・縮小（多数のSEEDを近づいて確認）
- SEEDをすぐドラッグ：球体上の位置を移動
- SEEDをタップ：内容を開く
- SEEDをダブルタップ：中心へ置く
- SEEDを長押しして別のSEEDへ重ねる：接続／接続解除
- 空白をダブルタップ、または右下の＋：新規作成
- 右上の•••：JSONバックアップ、読み込み、表示リセット

入力した内容は、利用中のブラウザ内に保存されます。

- 球体ガイドをズームと完全連動
- 画面全体を使うよう球体サイズを拡大

- 遠景：文字なしの空洞正方形

- 更新時に旧キャッシュが残りにくい方式へ変更


## v0.5

- SEED自体を惑星風の球体へ変更
- 遠景では球だけ / 中景では短いリング文字 / 近景では長めタイトル
- メインSEEDは太陽のように発光する中心核

- 通常SEEDのサイズをランダム生成、編集画面から変更可能
- 通常SEEDのサイズ上限はメインSEED未満

- 画面左下にワンボタンの「AUTO VIEW」を追加

# SEED — Spherical Notes

白い宇宙に自由記述メモを浮かべる、iPad向けの球体型Webアプリです。

## 操作

- 空白をドラッグ：球体を回転
- ピンチ：大きく拡大・縮小（多数のSEEDを近づいて確認）
- SEEDをすぐドラッグ：球体上の位置を移動
- SEEDをタップ：内容を開く
- SEEDをダブルタップ：中心へ置く
- SEEDを長押しして別のSEEDへ重ねる：接続／接続解除
- 空白をダブルタップ、または右下の＋：新規作成
- 右上の•••：JSONバックアップ、読み込み、表示リセット

入力した内容は、利用中のブラウザ内に保存されます。
